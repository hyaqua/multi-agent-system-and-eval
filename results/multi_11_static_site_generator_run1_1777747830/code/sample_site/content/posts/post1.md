# Getting Started with Static Sites

Static sites are **fast**, *secure*, and easy to deploy.

## Why Static Sites?

- No database required
- Blazing fast performance
- Easy to host anywhere
- Version control friendly

## Getting Started

1. Write your content in Markdown
2. Choose a static site generator
3. Deploy to a hosting service

> Static sites are the future of the web.

Here's a simple example:

```
python main.py --clean --serve
```

Learn more about [static sites](https://en.wikipedia.org/wiki/Static_web_page).
