# About This Site

This site was generated using a custom static site generator written in Python.

## How It Works

1. Write your content in Markdown files
2. Define templates with `{{variables}}`
3. Run the generator
4. Get a complete static website

The generator supports:

- **Headings** and *emphasis*
- [Links](https://python.org) and images
- Ordered and unordered lists
- Code blocks

```
def hello():
    print("Hello, world!")
```
