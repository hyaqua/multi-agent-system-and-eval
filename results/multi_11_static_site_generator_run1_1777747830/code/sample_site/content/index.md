# Welcome to My Static Site

This is a **static site generator** built with Python. It converts Markdown files
into a complete HTML website.

## Features

- Markdown to HTML conversion
- Template-based rendering
- Clean URLs
- Blog with date-sorted posts
- Automatic navigation

Check out the [About](/about/) page or visit the [Blog](/blog/).
