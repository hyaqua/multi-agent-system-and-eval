## Mastering Markdown

Markdown is more than just **bold** and *italic*. Let's explore some advanced techniques.

### Nested Lists

You can create nested lists for complex structures:

- Fruits
  - Apples
  - Bananas
- Vegetables
  - Carrots
  - Broccoli

### Code Blocks

Inline code looks like `this`. For larger blocks:

```javascript
function greet(name) {
    console.log(`Hello, ${name}!`);
}

greet('World');
```

### Links and References

Check out [Markdown Guide](https://www.markdownguide.org) for a complete reference.

Some style guides recommend using reference-style links:

[google]: https://www.google.com "Google"
