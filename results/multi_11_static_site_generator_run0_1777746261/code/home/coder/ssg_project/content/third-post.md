## Designing for the Web

In this third post, I want to talk about **web design principles**.

### Key Principles

1. **Clarity** - Make your content easy to read
2. **Consistency** - Use the same patterns throughout
3. **Accessibility** - Design for all users

### Accessibility Checklist

* Use proper heading hierarchy
* Add alt text to images
* Ensure sufficient color contrast
* Make links descriptive

Remember: *Good design is as little design as possible.*
