## About This Site

This is a sample static site generated from Markdown files.

### How It Works

The Static Site Generator reads Markdown files with YAML front matter and converts them into a complete HTML website:

1. Write content in Markdown
2. Add metadata in front matter
3. Run the generator
4. Deploy the output

### Features

* **Fast rendering** - Pure Python, no dependencies
* **Flexible templates** - Customize the look and feel
* **Clean URLs** - Every page gets its own directory
* **Built-in server** - Preview your site locally
