## Why Static Sites?

Static sites are making a **big comeback**. They're fast, secure, and easy to deploy. Unlike dynamic sites that generate pages on every request, static sites are pre-built and served as simple HTML files.

### Benefits of Static Sites

Here are some key advantages:

- **Speed** - No database queries, no server-side processing
- **Security** - No attack surface from dynamic code
- **Simplicity** - Just HTML, CSS, and JavaScript
- **Version Control** - Content can be stored in Git
