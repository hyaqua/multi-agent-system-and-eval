## About

This is a **static site** generated by a custom static site generator written in pure Python. No external dependencies required!

### How It Works

The generator reads Markdown files with front matter, converts them to HTML, applies templates, and outputs a complete static website.

Key features:

- Markdown to HTML conversion
- Template-based rendering
- Blog post support with date sorting
- Automatic navigation generation
- Clean URLs

### Why Build This?

Building your own tools is a great way to learn. This project demonstrates:

1. File I/O operations in Python
2. Text parsing and regex
3. HTML generation
4. Template engine design
5. CLI application development
