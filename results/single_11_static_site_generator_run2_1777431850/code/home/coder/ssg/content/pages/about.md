## About

Welcome to **My Static Site**! This is a demonstration site built with a custom static site generator written in Python.

### What Makes This Special?

This entire site is generated from:

- **Markdown files** with YAML-style front matter
- **HTML templates** with `{{variable}}` placeholders
- **Static assets** like CSS and images

No databases. No server-side code. Just pure HTML.

### Features

The generator supports:

1. Blog posts with dates and tags
2. Static pages like this one
3. Automatic navigation
4. Clean URLs
5. Syntax highlighting for code
6. A built-in development server

### Why Static?

Static sites are:

- **Fast** - No database queries
- **Secure** - No attack surface
- **Portable** - Host anywhere
- **Versionable** - Track in Git
