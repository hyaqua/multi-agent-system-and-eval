# About This Site

This site was built with a **custom static site generator** written in Python.

## Features

The generator supports:

- Markdown content with front matter
- Template-based rendering
- Blog posts with dates and tags
- Automatic navigation
- Clean URLs
- Built-in dev server

## Why Build Another Generator?

Because it's *fun* and educational! Building tools helps you understand:

1. How content transforms into HTML
2. How templates work under the hood
3. How static site generators like Jekyll and Hugo operate

## The Code

The entire generator is a single Python file using only the standard library. No dependencies needed!

Feel free to [browse the code](#) and modify it for your own needs.
