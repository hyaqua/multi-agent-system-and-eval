# Getting Started with Static Sites

Static sites are making a **comeback**. They're fast, secure, and easy to deploy.

## Why Static Sites?

Here are some reasons to consider a static site:

- **Speed**: No database queries, just static files
- **Security**: No server-side code to exploit
- **Simplicity**: Write content in Markdown, generate HTML
- **Version Control**: Store everything in Git

## Getting Started

First, you need a generator. This one is written in *pure Python* with no dependencies.

```python
def hello():
    print("Hello, static world!")
```

For more information, check out [the official Python docs](https://docs.python.org/3/).
